# UCM Deployer v{VERSION}

**UCM (Unified Cache Management) 安装与环境预检工具 —— Windows 桌面版**

面向 vLLM / vLLM-Ascend / SGLang 运行环境（Ascend NPU / NVIDIA GPU），提供五步向导：

```
① 服务器管理 → ② 镜像准备 → ③ 容器准备 → ④ 环境预检 → ⑤ 批量部署
```

## 本版本更新

- **步骤5 批量部署（多服务器）**：在一台服务器制作好镜像后，勾选多台目标服务器批量执行「镜像分发 → 容器创建 → 环境预检」；每台服务器独立进度条与独立日志页签，单台失败不影响其余继续执行。
- **镜像分发两种方式**：
  - **tar 包中转**：源服务器 `docker save | gzip` 导出 → 下载到本机 → 各目标并行上传并 `docker load`（源服务器作为面板首行先准备镜像包，目标就绪后并行分发），适合离线集群；
  - **镜像仓库**：各目标服务器直接 `docker pull`，无需源服务器；
  - 目标已存在同名镜像时可自动跳过分发（重复执行/增量补装场景）。
- **部署数据模板（JSON）导出/导入**：服务器登录信息 + 镜像来源 + 容器创建参数 + 预检参数一次填写、多机复用；登录密码默认不导出（确认后可包含），导入时按「主机+端口+用户名」匹配本地注册表（模板密码为空时保留本地密码），并自动勾选为目标。
- **设备差异自动适配**：容器创建逐台现场探测——Ascend 自动映射实际存在的 `/dev/davinci*` 等设备节点与驱动/工具挂载（存在 `/dev/ummu` 或 `/dev/uburma` 时自动 `--privileged`）；NVIDIA 使用 `--runtime nvidia --gpus all`；创建前校验镜像内 UCM 安装。
- **执行进展逐台可见**：进度按阶段权重映射（分发 45% / 创建 25% / 预检 30%，按勾选阶段自适应）；结束后汇总每台结果（镜像分发/跳过、容器名、预检三态判定）。
- **同名容器重建选项**：重复执行批量部署时，可勾选创建前先 `docker rm -f` 删除旧容器。
- **任务面板增强**：进度条/日志/结果按任务线程路由（同一服务器多任务互不覆盖），支持源服务器同时作为部署目标。
- **测试**：新增 41 项测试（模板序列化/校验、镜像分发、容器/预检流水线、多目标批量执行、模板往返导入、源即目标场景），全量 210 项通过。

## 主要功能

- **步骤1 服务器管理**：SSH 凭据本地加密保存/复用；自动探测设备型号、卡数与 CPU 架构。
- **步骤2 镜像准备**：支持服务器已有镜像、本地 tar 上传、镜像仓库拉取；自动探测基础镜像运行时并校验 UCM/wrapt/ucm-toolkit wheel 兼容性。
- **步骤3 容器准备**：选择 UCM 镜像自动校验安装情况；按宿主机实际存在的设备节点与系统挂载生成可编辑 `docker run` 命令；固定 Bash 入口，不启动推理服务；支持 KV Cache、模型与自定义挂载。
- **步骤4 环境预检**：显式选择容器；检查驱动、内核、共享内存、AIO 与存储带宽；UCM 与驱动版本支持多来源补齐；支持 JSON 参数叠加配置。
- **步骤5 批量部署**：多服务器镜像分发、容器创建与环境预检；部署数据模板导出/导入。
- **工具菜单**：按关键字筛选并清理容器/镜像，删除前展示完整确认列表。

## 使用

双击 `UCM-Deployer.exe` 即可（无需 Python）。产物自检：

```powershell
.\UCM-Deployer.exe --smoke
```

源码运行 / 开发见 [README](https://github.com/ucm-system/UCM-Deployer#readme)。
